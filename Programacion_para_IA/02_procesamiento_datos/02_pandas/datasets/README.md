# Datos de Titanic

`Titanic-Dataset.csv` procede del [dataset público de Titanic de Yasser H en Kaggle](https://www.kaggle.com/datasets/yasserh/titanic-dataset/data), la fuente indicada en `02_procesamiento_datos/02_pandas/FUENTES.md`.

Se conserva el CSV descargado sin modificar. Contiene 891 pasajeros y 12 columnas;
faltan 177 edades y 2 códigos de puerto de embarque. El proyecto de pandas lo lee
desde esta carpeta y guarda sus transformaciones en `outputs/`.
